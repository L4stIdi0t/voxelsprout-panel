# VoxelSprout Server Panel

A Minecraft server panel used from [voxelsprout.com](https://voxelsprout.com), through a small agent on your own machine. No port forwarding is needed to manage your server.

It installs and updates CurseForge modpacks and mods straight from CurseForge, so every download is counted and credited to the authors.

**Status:** in development. The source code is not public (all rights reserved).

By VoxelSprout, maker of BuildPrint, Sorted and Charted.
